# Gallery v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `/gallery` into the place where every binary in the hive is stored, filtered,
viewed, grouped in personal folders and tied to its home note, the notes that reference it and
the agent session that produced it — with browser upload as a second way in.

**Architecture:** Three new migrations carry all the rules: sessions (tagged by database
triggers from an `x-hive-session` request header), file links (`kind` column, references,
person-only home-note change, delete audit) and personal gallery folders. The MCP server only
sends the header and gains `hive_end_session`; the web gallery is rebuilt around a pure filter
model (client state, URL-backed), a session stream and grid, a file panel, an upload dialog and
browser-side previews (pdf.js, text, CSV).

**Tech Stack:** Postgres/Supabase (RLS, `security definer` functions, pg_cron), PGlite tests
(`node:test`), TypeScript MCP server (`@modelcontextprotocol/sdk`), Next.js 16 / React 19,
Vitest, Playwright, `pdfjs-dist`.

**Spec:** [`docs/superpowers/specs/2026-11-24-gallery-v2-design.md`](../specs/2026-11-24-gallery-v2-design.md)

## Global Constraints

- Sharing is decided in the database. No permission logic in `mcp/` or in `web/` beyond
  argument checks. Every rule change is a migration **plus a test**.
- Agents never set or change sharing, never change a file's home note, never remove a reference,
  never touch gallery folders, never delete. The database refuses these for any identity with an
  `agent_id` claim.
- Migrations are minted only with `scripts/new-migration.sh <slug>`; never hand-write a stamp,
  never edit a shipped migration.
- Text read from the hive is data: MCP reads go through `asData`; the web never renders file
  content as HTML (text/Markdown/CSV are text nodes; SVG and HTML are `other`).
- No `storage_path` in any value sent to the browser; signed links live 600 s.
- No colour literal outside `web/src/theme/` and `globals.css` (`web/src/gallery/no-literals.test.ts`).
- Page cap 200 files; file cap 50 MB; PDF viewer cap 25 MB; PDF thumbnail cap 5 MB; image
  thumbnail cap 2 MB; text preview first 512 KB; CSV preview first 500 rows.
- Session idle limit 2 hours; sweep every 15 minutes.
- Folder depth at most 2; folder name 1–60 characters after trimming.
- Session title 1–120 characters; summary at most 4000 characters.
- Commits authored `Danijel Jovanovic <info@synapse-solutions.ai>`; stage by explicit path only;
  conventional-commit messages ending with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Done = `pnpm typecheck && pnpm lint && pnpm test && pnpm build` green, plus the gallery browser
  suites (`pnpm --filter @hive-mind/web test:e2e -- gallery`).

```js
// Run SQL as a signed-in person or agent (claims), or as nobody (null).
// `headers` stands in for the request headers PostgREST passes on.
async function as(claims, sql, params = [], { headers } = {}) {
  await db.exec("reset role");
  await db.query(`select set_config('request.jwt.claims', $1, false)`, [
    JSON.stringify(claims ?? {}),
  ]);
  await db.query(`select set_config('request.headers', $1, false)`, [
    JSON.stringify(headers ?? {}),
  ]);
  await db.exec(`set role ${claims ? "authenticated" : "anon"}`);
  try {
    return (await db.query(sql, params)).rows;
  } finally {
    await db.exec("reset role");
  }
}
```

- [ ] **Step 4: Create `tests/helpers/hive.mjs`**

```js
// One hive with three members (dani owns it, ahmed and sara joined) and an
// outsider in a hive of their own, over the real migrations in PGlite. For the
// test files that do not need the whole of sharing-rules.test.mjs.
import { openDb } from "../../scripts/local-db.mjs";

export async function setupHive() {
  const { db, as, addMember } = await openDb();
  const users = {};
  const members = {};
  const ws = {};
  for (const name of ["dani", "ahmed", "sara", "outsider"]) {
    const r = await db.query(
      `insert into auth.users (email) values ($1) returning id`,
      [`${name}@example.com`],
    );
    users[name] = r.rows[0].id;
  }
  const person = (name) => ({ sub: users[name], role: "authenticated" });
  const hive = (
    await as(
      person("dani"),
      `select public.create_hive('Test hive', 'Dani') as id`,
    )
  )[0].id;
  await addMember(hive, users.ahmed, "Ahmed");
  await addMember(hive, users.sara, "Sara");
  await as(
    person("outsider"),
    `select public.create_hive('Other hive', 'Outsider')`,
  );
  for (const name of ["dani", "ahmed", "sara", "outsider"]) {
    const m = await as(
      person(name),
      `select m.id, w.id as ws from public.members m
         join public.workspaces w on w.member_id = m.id
        where m.user_id = $1 order by w.created_at limit 1`,
      [users[name]],
    );
    members[name] = m[0].id;
    ws[name] = m[0].ws;
  }

  const agentFor = async (name, tier = "vendor") => {
    const made = (
      await as(
        person(name),
        `select * from public.create_agent($1, 'Test agent', 'other', $2)`,
        [ws[name], tier],
      )
    )[0];
    const login = (
      await as(null, `select * from public.agent_login($1)`, [made.token])
    )[0];
    return {
      sub: login.user_id,
      role: "authenticated",
      agent_id: login.agent_id,
      workspace_id: login.workspace_id,
      trust_tier: login.trust_tier,
    };
  };

  const addNote = async (name, title, extra = {}) =>
    (
      await as(
        extra.as ?? person(name),
        `insert into public.notes (hive_id, member_id, workspace_id, path, title, body, visibility, shared_with)
         values ($1, $2, $3, $4, $5, 'body', $6, $7) returning id, session_id`,
        [
          hive,
          members[name],
          ws[name],
          extra.path ?? `${title}.md`,
          title,
          extra.visibility ?? null,
          extra.shared_with ?? [],
        ],
        { headers: extra.headers },
      )
    )[0];

  // A stored object plus its files row, as hive_save_file makes them.
  const saveFile = async (who, owner, file, opts = {}) => {
    const path = `${members[owner]}/${ws[owner]}/outputs/proposal/acme/${file}`;
    const mime =
      opts.mime ?? (file.endsWith(".pdf") ? "application/pdf" : null);
    await as(
      who,
      `insert into storage.objects (bucket_id, name) values ('files', $1)`,
      [path],
      {
        headers: opts.headers,
      },
    );
    return (
      await as(
        who,
        `insert into public.files (hive_id, member_id, workspace_id, note_id, storage_path, name, mime, size_bytes)
         values ($1, $2, $3, $4, $5, $6, $7, 100) returning id, session_id`,
        [
          hive,
          members[owner],
          ws[owner],
          opts.note_id ?? null,
          path,
          file,
          mime,
        ],
        { headers: opts.headers },
      )
    )[0];
  };

  return {
    db,
    as,
    person,
    agentFor,
    members,
    ws,
    hive,
    users,
    addNote,
    saveFile,
  };
}
```

```sql
-- <stamp>_sessions.sql
-- Version minted by scripts/new-migration.sh (real UTC stamp). Do not hand-edit
-- the version, and never edit a migration that has shipped.
--
-- What this migration does:
--   Records an agent's working run as a session, tags every note and file it
--   writes with it, and closes it into a session note.
--
--   - public.sessions: one row per run. Read by its owner, or by anyone who can
--     read its session note. Written only by the functions below.
--   - notes.session_id, files.session_id: filled by the tagging trigger, never
--     by the client. The key comes from the request header x-hive-session
--     (stdio MCP: one per process; no header: 'default').
--   - session_end(title, summary): an agent closes its open session; writes
--     the session note at Sessions/<date> <title>.md (sharing inherited, like
--     any note), lists what the session produced as plain text (no wiki links,
--     which would propose links), and makes that note the home of the
--     session's files that have none.
--   - close_idle_sessions(): the scheduled sweep (scripts/setup-session-sweep.sh)
--     closes sessions idle for two hours. An idle session is also closed by
--     its agent's next write.
--   - upload_session_open/end, session_retitle: a person's upload batch and a
--     person retitling their own session.

create table public.sessions (
  id uuid primary key default gen_random_uuid(),
  hive_id uuid not null references public.hives on delete cascade,
  member_id uuid not null references public.members on delete cascade,
  workspace_id uuid not null references public.workspaces on delete cascade,
  agent_id uuid references public.agents on delete set null,
  agent_name text not null,
  client_key text not null,
  title text,
  summary text,
  note_id uuid references public.notes on delete set null,
  started_at timestamptz not null default now(),
  last_active_at timestamptz not null default now(),
  ended_at timestamptz
);
create unique index sessions_open_key on public.sessions (member_id, client_key)
  where ended_at is null;
create index sessions_hive_started_idx on public.sessions (hive_id, started_at desc);
create index sessions_idle_idx on public.sessions (last_active_at) where ended_at is null;
create index sessions_note_idx on public.sessions (note_id);

alter table public.sessions enable row level security;
create policy sessions_select on public.sessions for select to authenticated
  using ((member_id in (select public.my_member_ids()) and not public.jwt_is_self_hosted())
         or exists (select 1 from public.notes n where n.id = note_id));
create policy sessions_no_app on public.sessions as restrictive for all to authenticated
  using (public.jwt_oauth_client() is null)
  with check (public.jwt_oauth_client() is null);

alter table public.notes add column session_id uuid references public.sessions on delete set null;
alter table public.files add column session_id uuid references public.sessions on delete set null;
create index notes_session_idx on public.notes (session_id);
create index files_session_idx on public.files (session_id);

-- ------------------------------------------------------------ the key

create function public.request_session_key() returns text
language sql stable set search_path = '' as $$
  select case
    when k ~ '^[A-Za-z0-9-]{1,64}$' then k
    else 'default'
  end
  from (select coalesce(nullif(current_setting('request.headers', true), ''), '{}')::jsonb
               ->> 'x-hive-session' as k) h
$$;

-- ------------------------------------------------------------ closing

create function public._session_title(s public.sessions) returns text
language sql stable security definer set search_path = '' as $$
  select coalesce(
    (select split_part(f.storage_path, '/', 4) || ' / ' || split_part(f.storage_path, '/', 5)
       from public.files f
      where f.session_id = s.id and split_part(f.storage_path, '/', 3) = 'outputs'
      group by 1 order by count(*) desc, 1 limit 1),
    'Session · ' || s.agent_name || ' · ' || to_char(s.started_at at time zone 'UTC', 'YYYY-MM-DD'))
$$;

-- Closes one open session: writes its note, homes its homeless files. Returns
-- the note id. Internal.
create function public._close_session(p_id uuid, p_title text, p_summary text)
returns uuid
language plpgsql security definer set search_path = '' as $$
declare
  s public.sessions;
  v_title text;
  v_body text;
  v_base text;
  v_path text;
  v_n int := 1;
  v_note uuid;
begin
  select * into s from public.sessions where id = p_id for update;
  if not found then raise exception 'no such session'; end if;
  if s.ended_at is not null then return s.note_id; end if;

  v_title := coalesce(nullif(btrim(p_title), ''), public._session_title(s));
  v_body := coalesce(nullif(btrim(p_summary), ''), 'Closed automatically.')
    || E'\n\n## Produced in this session\n'
    || coalesce((select string_agg('- note: ' || n.title || ' (' || n.path || ')', E'\n' order by n.created_at)
                   from public.notes n where n.session_id = s.id), '')
    || E'\n'
    || coalesce((select string_agg('- file: ' || f.name, E'\n' order by f.created_at)
                   from public.files f where f.session_id = s.id), '');

  v_base := 'Sessions/' || to_char(s.started_at at time zone 'UTC', 'YYYY-MM-DD') || ' '
    || left(regexp_replace(v_title, '[/\\\[\]#|^]', '-', 'g'), 80);
  v_path := v_base || '.md';
  while exists (select 1 from public.notes where workspace_id = s.workspace_id and path = v_path) loop
    v_n := v_n + 1;
    v_path := v_base || ' (' || v_n || ').md';
  end loop;

  -- The note belongs to this session; the tagging trigger reads this.
  perform set_config('hive.closing_session', s.id::text, true);
  insert into public.notes (hive_id, member_id, workspace_id, path, title, body)
  values (s.hive_id, s.member_id, s.workspace_id, v_path, v_title, v_body)
  returning id into v_note;
  perform set_config('hive.closing_session', '', true);

  update public.sessions
     set title = v_title,
         summary = coalesce(nullif(btrim(p_summary), ''), 'Closed automatically.'),
         note_id = v_note,
         ended_at = now()
   where id = s.id;
  update public.files set note_id = v_note where session_id = s.id and note_id is null;
  return v_note;
end
$$;

-- The calling agent's open session for this request's key, opened or bumped.
-- An open session idle for two hours is closed first. Internal.
create function public._agent_session() returns uuid
language plpgsql security definer set search_path = '' as $$
declare
  a public.agents;
  k text;
  s public.sessions;
  v_id uuid;
begin
  select * into a from public.agents where id = public.jwt_agent_id();
  if not found then return null; end if;
  k := a.id::text || ':' || public.request_session_key();
  select * into s from public.sessions
   where member_id = a.member_id and client_key = k and ended_at is null
   for update;
  if found and s.last_active_at < now() - interval '2 hours' then
    perform public._close_session(s.id, null, null);
  elsif found then
    update public.sessions set last_active_at = now() where id = s.id;
    return s.id;
  end if;
  insert into public.sessions (hive_id, member_id, workspace_id, agent_id, agent_name, client_key)
  select w.hive_id, a.member_id, a.workspace_id, a.id, a.name, k
    from public.workspaces w where w.id = a.workspace_id
  returning id into v_id;
  return v_id;
end
$$;

-- ------------------------------------------------------------ tagging

create function public.tag_session() returns trigger
language plpgsql security definer set search_path = '' as $$
declare
  v_closing text := current_setting('hive.closing_session', true);
begin
  if v_closing is not null and v_closing <> '' then
    new.session_id := v_closing::uuid;
    return new;
  end if;
  if public.jwt_agent_id() is not null then
    if tg_op = 'INSERT' then
      new.session_id := public._agent_session();
    else
      perform public._agent_session();
      new.session_id := old.session_id;
    end if;
    return new;
  end if;
  if tg_op = 'UPDATE' then
    new.session_id := old.session_id;
    return new;
  end if;
  -- A person: only their own open upload session.
  if new.session_id is not null and not exists (
       select 1 from public.sessions s
        where s.id = new.session_id and s.agent_id is null and s.ended_at is null
          and s.member_id = new.member_id
          and s.member_id in (select public.my_member_ids())) then
    raise exception 'not your upload session';
  end if;
  return new;
end
$$;

create trigger notes_tag_session before insert or update on public.notes
  for each row execute function public.tag_session();
create trigger files_tag_session before insert on public.files
  for each row execute function public.tag_session();

-- ------------------------------------------------------------ callable

create function public.session_end(p_title text, p_summary text) returns jsonb
language plpgsql security definer set search_path = '' as $$
declare
  a public.agents;
  s public.sessions;
  v_note uuid;
begin
  if public.jwt_agent_id() is null then
    raise exception 'only an agent ends a session';
  end if;
  if p_title is null or char_length(btrim(p_title)) not between 1 and 120 then
    raise exception 'a session title is 1 to 120 characters';
  end if;
  if p_summary is not null and char_length(p_summary) > 4000 then
    raise exception 'a session summary is at most 4000 characters';
  end if;
  select * into a from public.agents where id = public.jwt_agent_id();
  select * into s from public.sessions
   where member_id = a.member_id
     and client_key = a.id::text || ':' || public.request_session_key()
     and ended_at is null;
  if not found then raise exception 'no open session: nothing was written in it yet'; end if;
  v_note := public._close_session(s.id, p_title, p_summary);
  return jsonb_build_object(
    'session_id', s.id,
    'note_id', v_note,
    'note_path', (select path from public.notes where id = v_note));
end
$$;

create function public.close_idle_sessions() returns integer
language plpgsql security definer set search_path = '' as $$
declare
  v_id uuid;
  v_n int := 0;
begin
  for v_id in
    select id from public.sessions
     where ended_at is null and agent_id is not null
       and last_active_at < now() - interval '2 hours'
     order by last_active_at limit 500
  loop
    perform public._close_session(v_id, null, null);
    v_n := v_n + 1;
  end loop;
  return v_n;
end
$$;

create function public.upload_session_open(p_workspace uuid) returns uuid
language plpgsql security definer set search_path = '' as $$
declare

  v_id uuid;

  insert into public.sessions (hive_id, member_id, workspace_id, agent_name, client_key)
  values (w.hive_id, w.member_id, w.id, 'Browser upload', 'upload:' || gen_random_uuid())
  returning id into v_id;
  return v_id;
end
$$;

create function public.upload_session_end(p_session uuid, p_note uuid) returns void
```

```bash
#!/usr/bin/env bash
#
# setup-session-sweep.sh [--project-ref <ref>]
#
# Schedules the sweep that closes agent sessions idle for two hours, once per
# Supabase project, after the sessions migration is applied. It enables
# pg_cron if needed and (re)schedules the job `close-idle-sessions` every 15
# minutes. The job runs SQL inside the database; no secret is involved.
#
# Needs the Supabase CLI (signed in: `supabase login`). No Docker.
set -euo pipefail

REF_ARGS=()
if [ "${1:-}" = "--project-ref" ]; then REF_ARGS=(--project-ref "$2"); fi
```

```sql
-- <stamp>_file_links.sql
-- Version minted by scripts/new-migration.sh (real UTC stamp). Do not hand-edit
-- the version, and never edit a migration that has shipped.
--
-- What this migration does:
--   - files.kind: what a file is for showing it, decided once on insert from
--     the name's extension and the declared type together (a mismatch is
--     'other'; SVG and HTML are always 'other'). Same table as
--     web/src/gallery/kind.ts; both are tested against tests/fixtures/kind-cases.json.
--   - Indexes for the gallery's bounded reads: (hive_id, created_at, id) and
--     (hive_id, kind, created_at).
--   - public.file_references: a note mentions a file. Grants no access:
--     files_select does not look at it. A row shows only to someone who can
--     read both the file and the note.
--   - file_set_home: a person moves a file's home note (who may read it
--     follows the home note). Owner only, never an agent; audited.
--   - files_deleted_audit: deleting a file writes one audit row (file id only).

create function public.file_kind(p_name text, p_mime text) returns text
language sql immutable set search_path = '' as $$
  select case
    when ext in ('png') then case when m = 'image/png' then 'image' else 'other' end
    when ext in ('jpg', 'jpeg') then case when m = 'image/jpeg' then 'image' else 'other' end
    when ext = 'gif' then case when m = 'image/gif' then 'image' else 'other' end
    when ext = 'webp' then case when m = 'image/webp' then 'image' else 'other' end
    when ext = 'avif' then case when m = 'image/avif' then 'image' else 'other' end
    when ext = 'pdf' then case when m = 'application/pdf' then 'pdf' else 'other' end
    when ext in ('md', 'txt') then case when m in ('text/markdown', 'text/plain') then 'text' else 'other' end
    when ext = 'csv' then case when m in ('text/csv', 'text/plain') then 'csv' else 'other' end
    when ext = 'pptx' then 'slides'
    when ext = 'xlsx' then 'sheet'
    when ext = 'docx' then 'doc'
    else 'other'
  end
  from (select lower(substring(coalesce(p_name, '') from '\.([^./]+)$')) as ext,
               lower(btrim(split_part(coalesce(p_mime, ''), ';', 1))) as m) x
$$;

alter table public.files add column kind text;
update public.files set kind = public.file_kind(name, mime);
alter table public.files alter column kind set not null;

create function public.files_set_kind() returns trigger
language plpgsql set search_path = '' as $$
begin
  new.kind := public.file_kind(new.name, new.mime);
  return new;
end
$$;
create trigger files_set_kind before insert on public.files
  for each row execute function public.files_set_kind();

create index files_hive_created_idx on public.files (hive_id, created_at desc, id desc);
create index files_hive_kind_idx on public.files (hive_id, kind, created_at desc);

-- ------------------------------------------------------------ references

create table public.file_references (
  file_id uuid not null references public.files on delete cascade,
  note_id uuid not null references public.notes on delete cascade,
  created_by_agent uuid references public.agents on delete set null,
  created_at timestamptz not null default now(),
  primary key (file_id, note_id)
);
create index file_references_note_idx on public.file_references (note_id);
alter table public.file_references enable row level security;

create function public.file_references_before_insert() returns trigger
language plpgsql set search_path = '' as $$
begin
  new.created_by_agent := public.jwt_agent_id();
  new.created_at := now();
  return new;
end
$$;
create trigger file_references_before_insert before insert on public.file_references
  for each row execute function public.file_references_before_insert();

-- Both lookups run under the caller's own row-level security.
create policy file_references_select on public.file_references for select to authenticated
  using (exists (select 1 from public.files f where f.id = file_id)
         and exists (select 1 from public.notes n where n.id = note_id));
create policy file_references_insert on public.file_references for insert to authenticated
  with check (exists (select 1 from public.files f where f.id = file_id)
              and exists (select 1 from public.notes n
                           where n.id = note_id
                             and n.member_id in (select public.my_member_ids())
                             and public.agent_write_ok(n.workspace_id)));
create policy file_references_delete on public.file_references for delete to authenticated
  using (public.jwt_agent_id() is null
         and exists (select 1 from public.notes n
                      where n.id = note_id and n.member_id in (select public.my_member_ids())));
create policy file_references_no_app on public.file_references as restrictive for all to authenticated
  using (public.jwt_oauth_client() is null)
  with check (public.jwt_oauth_client() is null);

-- ------------------------------------------------------------ home note

create function public.file_set_home(p_file uuid, p_note uuid) returns void
language plpgsql security definer set search_path = '' as $$
declare
  f public.files;
begin
  if public.jwt_agent_id() is not null or public.jwt_oauth_client() is not null
     or public.jwt_is_self_hosted() or (select auth.uid()) is null then
    raise exception 'only a person changes where a file lives';
  end if;
  select * into f from public.files
   where id = p_file and member_id in (select public.my_member_ids());
  if not found then raise exception 'no such file'; end if;
  if p_note is not null and not exists (
       select 1 from public.notes n where n.id = p_note and n.member_id = f.member_id) then
    raise exception 'a file can only live in your own note';
  end if;
  if f.note_id is not distinct from p_note then return; end if;
  update public.files set note_id = p_note where id = f.id;
  insert into public.audit_log (hive_id, member_id, action, detail)
  values (f.hive_id, f.member_id, 'file.home_changed',
          jsonb_build_object('file_id', f.id, 'from', f.note_id, 'to', p_note));
end
$$;
revoke all on function public.file_set_home(uuid, uuid) from public, anon;
grant execute on function public.file_set_home(uuid, uuid) to authenticated;

-- ------------------------------------------------------------ delete audit

-- Same guards as notes_deleted_audit: no row for a service delete, none when
-- the whole hive is going.
create function public.files_deleted_audit() returns trigger
language plpgsql security definer set search_path = '' as $$
declare
  v_uid uuid := (select auth.uid());
begin
  if v_uid is null
     or not exists (select 1 from public.hives h where h.id = old.hive_id) then
    return old;
  end if;
  insert into public.audit_log (hive_id, member_id, agent_id, action, detail)
  values (
    old.hive_id,
    (select m.id from public.members m where m.hive_id = old.hive_id and m.user_id = v_uid),
    public.jwt_agent_id(),
    'file.deleted',
    jsonb_build_object('file_id', old.id));
  return old;
end
$$;
create trigger files_deleted_audit before delete on public.files
  for each row execute function public.files_deleted_audit();

revoke all on function public.files_deleted_audit() from public, anon, authenticated;
revoke all on function public.files_set_kind() from public, anon, authenticated;
revoke all on function public.file_references_before_insert() from public, anon, authenticated;
```

```sql
  id uuid primary key default gen_random_uuid(),
  member_id uuid not null references public.members on delete cascade,
  parent_id uuid references public.gallery_folders on delete cascade,
  name text not null check (char_length(btrim(name)) between 1 and 60),
  created_at timestamptz not null default now()
);
create unique index gallery_folders_name_idx on public.gallery_folders
  (member_id, coalesce(parent_id, '00000000-0000-0000-0000-000000000000'::uuid), lower(btrim(name)));
create index gallery_folders_parent_idx on public.gallery_folders (parent_id);

create table public.gallery_folder_files (
  folder_id uuid not null references public.gallery_folders on delete cascade,
  file_id uuid not null references public.files on delete cascade,
  added_at timestamptz not null default now(),
  primary key (folder_id, file_id)
);
create index gallery_folder_files_file_idx on public.gallery_folder_files (file_id);

create function public.gallery_folders_before_write() returns trigger
language plpgsql security definer set search_path = '' as $$
declare
  p public.gallery_folders;
begin
  new.name := btrim(new.name);
  if new.parent_id is not null then
    select * into p from public.gallery_folders where id = new.parent_id;
    if not found or p.member_id <> new.member_id then
      raise exception 'a folder can only sit in your own folder';
    end if;
    if p.parent_id is not null then
      raise exception 'folders go two levels deep at most';
    end if;
    if tg_op = 'UPDATE' and exists (
         select 1 from public.gallery_folders c where c.parent_id = new.id) then
      raise exception 'folders go two levels deep at most';
    end if;
  end if;
  if tg_op = 'UPDATE' and new.member_id <> old.member_id then
    raise exception 'a folder cannot change hands';
  end if;
  return new;
end
$$;
```

```ts
  text: "Text",

/** Kinds whose declared type must agree with the extension. */
const CHECKED = new Map<string, [Kind, string[]]>([
  ["png", ["image", ["image/png"]]],
  ["jpg", ["image", ["image/jpeg"]]],
  ["jpeg", ["image", ["image/jpeg"]]],
  ["gif", ["image", ["image/gif"]]],
  ["webp", ["image", ["image/webp"]]],
  ["avif", ["image", ["image/avif"]]],
  ["pdf", ["pdf", ["application/pdf"]]],
  ["md", ["text", ["text/markdown", "text/plain"]]],
  ["txt", ["text", ["text/markdown", "text/plain"]]],
  ["csv", ["csv", ["text/csv", "text/plain"]]],
]);

const BY_NAME = new Map<string, Kind>([
  ["pptx", "slides"],
  ["xlsx", "sheet"],
  ["docx", "doc"],
]);

function extension(name: string): string {
  const m = /\.([^./]+)$/.exec(name);
  return m ? m[1]!.toLowerCase() : "";
}

export function fileKind(name: string, mime: string | null): Kind {
  const ext = extension(name);
  const checked = CHECKED.get(ext);
  if (checked) {
    const declared = (mime ?? "").split(";")[0]!.trim().toLowerCase();
    return checked[1].includes(declared) ? checked[0] : "other";
  }
  return BY_NAME.get(ext) ?? "other";
}

export function kindLabel(kind: Kind, name: string): string {
  if (kind === "pdf") return "PDF";
  const ext = extension(name);
  return /^[a-z0-9]{1,5}$/.test(ext) ? ext.toUpperCase() : "FILE";
}
```

```ts
// The gallery's filter model. Pure: chips, scope, folder and view are client state backed by the
// URL, and over the loaded files they make no request. `needsServer` says when the loaded set
// cannot answer (more exist and a server-side filter is on).
import { PDF_VIEW_MAX } from "./kind";
import type {
  DatePreset,
  Filters,
  GalleryFile,
  GalleryFolder,
  GallerySession,
  Kind,
  Scope,
  ServerFilter,
  View,
} from "./types";

const KINDS: Kind[] = [
  "image",
  "pdf",
  "slides",
  "sheet",
  "doc",
  "text",
  "csv",
  "other",
];
const VIEWS: View[] = ["session", "grid"];
const SCOPES: Scope[] = ["all", "mine", "shared"];
const DATES: DatePreset[] = ["any", "today", "week", "month", "range"];
const DAY = 86_400_000;
const ID = /^[0-9a-f-]{36}$/i;
const YMD = /^\d{4}-\d{2}-\d{2}$/;

export const DEFAULT_FILTERS: Filters = {
  view: "session",
  scope: "all",
  folder: null,
  kinds: [],
  date: "any",
  from: null,
  to: null,
  session: null,
  agent: null,
  owner: null,
  q: "",
};

const pick = <T extends string>(
  v: string | null,
  all: readonly T[],
  d: T,
): T => (v !== null && (all as readonly string[]).includes(v) ? (v as T) : d);
const id = (v: string | null) => (v && ID.test(v) ? v : null);

export function fromQuery(p: URLSearchParams): Filters {
  const kinds = (p.get("kinds") ?? "")
    .split(",")
    .filter((k): k is Kind => (KINDS as string[]).includes(k));
  let date = pick(p.get("date"), DATES, "any");
  const from = p.get("from"),
    to = p.get("to");
  const range =
    date === "range" && from && to && YMD.test(from) && YMD.test(to);
  if (date === "range" && !range) date = "any";
  return {
    view: pick(p.get("view"), VIEWS, "session"),
    scope: pick(p.get("scope"), SCOPES, "all"),
    folder: id(p.get("folder")),
    kinds,
    date,
    from: range ? from : null,
    to: range ? to : null,
    session: id(p.get("session")),
    agent: (p.get("agent") ?? "").slice(0, 80) || null,
    owner: id(p.get("owner")),
    q: (p.get("q") ?? "").slice(0, 200),
  };
}

export function toQuery(f: Filters): string {
  const p = new URLSearchParams();
  if (f.view !== "session") p.set("view", f.view);
  if (f.scope !== "all") p.set("scope", f.scope);
  if (f.folder) p.set("folder", f.folder);
  if (f.kinds.length) p.set("kinds", f.kinds.join(","));
  if (f.date !== "any") p.set("date", f.date);
  if (f.date === "range" && f.from && f.to) {
    p.set("from", f.from);
    p.set("to", f.to);
  }
  if (f.session) p.set("session", f.session);
  if (f.agent) p.set("agent", f.agent);
  if (f.owner) p.set("owner", f.owner);
  if (f.q) p.set("q", f.q);
  return p.toString();
}

const startOfDay = (t: number) => Math.floor(t / DAY) * DAY;

export function dateBounds(
  f: Filters,
  now: number,
): { from: number; to: number } | null {
  const end = startOfDay(now) + DAY;
  switch (f.date) {
    case "today":
      return { from: end - DAY, to: end };
    case "week":
      return { from: end - 7 * DAY, to: end };
    case "month":
      return { from: end - 30 * DAY, to: end };
    case "range":
      return f.from && f.to
        ? {
            from: Date.parse(`${f.from}T00:00:00Z`),
            to: Date.parse(`${f.to}T00:00:00Z`) + DAY,
          }
        : null;
    default:
      return null;
  }
}

export function applyFilters(
  files: GalleryFile[],
  f: Filters,
  sessions: Map<string, GallerySession>,
  folderFiles: (folderId: string) => Set<string>,
  now: number,
): GalleryFile[] {
  const needle = f.q.trim().toLowerCase();
  const bounds = dateBounds(f, now);
  const inFolder = f.folder ? folderFiles(f.folder) : null;
  return files.filter((x) => {
    if (f.scope === "mine" && !x.mine) return false;
    if (f.scope === "shared" && x.mine) return false;
    if (inFolder && !inFolder.has(x.id)) return false;
    if (f.kinds.length && !f.kinds.includes(x.kind)) return false;
    if (bounds) {
      const t = Date.parse(x.created_at);
      if (!(t >= bounds.from && t < bounds.to)) return false;
    }
    if (f.session && x.session_id !== f.session) return false;
    if (
      f.agent &&
      (x.session_id ? sessions.get(x.session_id)?.agent : undefined) !== f.agent
    )
      return false;
    if (f.owner && x.owner_id !== f.owner) return false;
    if (needle && !x.name.toLowerCase().includes(needle)) return false;
    return true;
  });
}

export function groupBySession(
  files: GalleryFile[],
  sessions: Map<string, GallerySession>,
) {
  const groups = new Map<string | null, GalleryFile[]>();
  for (const x of files) {
    const key =
      x.session_id && sessions.has(x.session_id) ? x.session_id : null;
    (groups.get(key) ?? groups.set(key, []).get(key)!).push(x);
  }
  return [...groups.entries()]
    .map(([key, list]) => ({
      session: key ? sessions.get(key)! : null,
      files: list,
    }))
    .sort((a, b) =>
      a.session === null
        ? 1
        : b.session === null
          ? -1
          : b.session.started_at.localeCompare(a.session.started_at),
    );
}

export function needsServer(f: Filters, complete: boolean): boolean {
  if (complete) return false;
  return (
    f.kinds.length > 0 ||
    f.date !== "any" ||
    !!f.session ||
    !!f.agent ||
    !!f.owner ||
    !!f.folder
  );
}

export function toServerFilter(
  f: Filters,
  now: number,
  folderFileIds: string[] | null,
): ServerFilter {
  const b = dateBounds(f, now);
  return {
    kinds: f.kinds,
    session: f.session,
    owner: f.owner,
    from: b ? new Date(b.from).toISOString() : null,
    to: b ? new Date(b.to).toISOString() : null,
    ids: folderFileIds ? folderFileIds.slice(0, 200) : null,
  };
}

export function folderTree(folders: GalleryFolder[]) {
  const byName = (a: GalleryFolder, b: GalleryFolder) =>
    a.name.localeCompare(b.name, undefined, { sensitivity: "base" });
  return folders
    .filter((x) => x.parent_id === null)
    .sort(byName)
    .map((folder) => ({
      folder,
      children: folders.filter((c) => c.parent_id === folder.id).sort(byName),
    }));
}

export function scopeCounts(files: GalleryFile[]): Record<Scope, number> {
  const mine = files.filter((x) => x.mine).length;

}

export function viewable(f: GalleryFile): boolean {

    f.kind === "text" ||
    f.kind === "csv" ||

  );
}
```

```ts
// web/src/gallery/csv.ts
// A small RFC 4180 reader for the CSV preview. Cells come back as plain strings and are only
// ever drawn as text.
export function parseCsv(
  text: string,
  maxRows: number,
): { rows: string[][]; truncated: boolean } {
  const rows: string[][] = [];
  let row: string[] = [];
  let cell = "";
  let quoted = false;
  let i = 0;
  const endRow = () => {
    row.push(cell);
    rows.push(row);
    row = [];
    cell = "";
  };
  while (i < text.length) {
    const c = text[i]!;
    if (quoted) {
      if (c === '"' && text[i + 1] === '"') {
        cell += '"';
        i += 2;
        continue;
      }
      if (c === '"') {
        quoted = false;
        i++;
        continue;
      }
      cell += c;
      i++;
      continue;
    }
    if (c === '"' && cell === "") {
      quoted = true;
      i++;
      continue;
    }
    if (c === ",") {
      row.push(cell);
      cell = "";
      i++;
      continue;
    }
    if (c === "\r" || c === "\n") {
      endRow();
      i += c === "\r" && text[i + 1] === "\n" ? 2 : 1;
      if (rows.length === maxRows) return { rows, truncated: i < text.length };
      continue;
    }
    cell += c;
    i++;
  }
  if (cell !== "" || row.length) endRow();
  return { rows, truncated: false };
}
```

```ts
// Fetches a file for a preview and refuses anything that is not what it claims. The declared
// type was set by whoever saved the file, so it is never enough: a PDF must start with "%PDF-",
// text and CSV must not come back as HTML or SVG, and nothing is shown past its cap (text is cut,
// PDFs are refused).
import type { Kind } from "../types";

type Out =
  { ok: true; blob: Blob } | { ok: false; reason: "type" | "size" | "network" };
const ALLOWED: Partial<Record<Kind, string[]>> = {
  pdf: ["application/pdf"],
  text: ["text/plain", "text/markdown"],
  csv: ["text/csv", "text/plain"],
};

export async function fetchChecked(
  url: string,
  kind: Kind,
  maxBytes: number,
): Promise<Out> {
  let res: Response;
  try {
    res = await fetch(url, { credentials: "omit", redirect: "error" });
  } catch {
    return { ok: false, reason: "network" };
  }
  if (!res.ok) return { ok: false, reason: "network" };
  const type = (res.headers.get("content-type") ?? "")
    .split(";")[0]!
    .trim()
    .toLowerCase();
  if (!(ALLOWED[kind] ?? []).includes(type))
    return { ok: false, reason: "type" };
  const blob = await res.blob();
  if (kind === "pdf") {
    if (blob.size > maxBytes) return { ok: false, reason: "size" };
    const head = new TextDecoder().decode(await blob.slice(0, 5).arrayBuffer());
    if (head !== "%PDF-") return { ok: false, reason: "type" };
    return { ok: true, blob: new Blob([blob], { type: "application/pdf" }) };
  }
  return { ok: true, blob: blob.slice(0, maxBytes, "text/plain") };
}
```

upload action set it from the extension, so a correct file passes.)

## Performance and data-fetching budget (from the spec, as built)

- **First paint:** 4 waves, all bounded: hive; members + files (≤ 201, `files_hive_created_idx`)
  - my folders + my memberships (≤ 5000, owner-only); home notes + references + sessions by id
    (chunks of 50) + one batched signing call; session-note titles (≤ 50 ids).
- **Scope, chips, folder, view, selection, panel:** 0 requests while the loaded set is complete;
  otherwise 1 debounced `loadPage` per filter change, filtered on indexed columns, ≤ 200 rows.
- **Writes:** folder create/rename/delete, membership add/remove, set home, upload (start,
  one PUT per file to storage, finish per file, end), delete: each updates loaded state in place.
- **Previews:** PDF thumbnails rendered in the browser only when visible, ≤ 4 at once, cached by
  file id; the viewer asks for a fresh link per file shown.
