# Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the placeholder hexagon with the linked-hive mark and the HIVE MIND wordmark
([spec](../specs/2026-11-24-logo-design.md)).

**Architecture:** Two small React components in `web/src/brand/` draw the mark as inline SVG
coloured only by theme variables; the rail, the sign-in cards and the consent page use them. A
static `icon.svg` is the favicon.

**Tech Stack:** Next.js 16 App Router, React 19, CSS modules, Vitest, Playwright.

## Global Constraints

- No colour literals in `.ts`, `.tsx`, `.css` under `web/src` (the `no-literals` tests).
- Mark colours: left `var(--mark)`, right `var(--fresh-4)`, link and right node `var(--fresh-7)`,
  left node `var(--mark)`.
- Wordmark: HIVE Inter 700 `var(--text)`, MIND Inter 300 `var(--muted)`, letter spacing 0.08em,
  capitals by CSS; accessible text "Hive Mind".
- The rail's text beside the mark stays the hive switcher.

```tsx
// web/src/brand/Mark.tsx
import s from "./brand.module.css";

/** The linked hive: two halves of a hexagon joined by one link. Colours come from the theme. */
export function Mark({
  size = 18,
  className,
}: {
  size?: number;
  className?: string;
}) {
  return (
    <svg
      viewBox="0 0 48 48"
      width={size}
      height={size}
      aria-hidden="true"
      focusable="false"
      className={className ? `${s.mark} ${className}` : s.mark}
    >
      <g
        fill="none"
        strokeWidth={3.4}
        strokeLinecap="round"
        strokeLinejoin="round"
      >
        <path d="M20 7.6 L8.4 14.3 L8.4 33.7 L20 40.4" stroke="var(--mark)" />
        <path
          d="M28 7.6 L39.6 14.3 L39.6 33.7 L28 40.4"
          stroke="var(--fresh-4)"
        />
        <path data-link="" d="M17 24 L31 24" stroke="var(--fresh-7)" />
      </g>
      <circle cx={17} cy={24} r={4} fill="var(--mark)" />
      <circle data-link="" cx={31} cy={24} r={4} fill="var(--fresh-7)" />
    </svg>
  );
}
```
